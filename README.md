# Mizan — UAE Legal Research

A zero-build, GitHub Pages-ready edition of Mizan.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will provide a public URL after deployment completes.

The legal index is a curated informational starting point, not legal advice. Verify current consolidated texts with official UAE sources.
